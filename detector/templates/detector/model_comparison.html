Evaluation protocol

  1. The dataset is loaded exactly as provided, labels are normalised to ham/spam and exact duplicate messages are removed ({{ dataset.duplicate_rows }} duplicates found, {{ dataset.rows_removed_as_duplicates }} removed).
  2. The remaining {{ dataset.rows_after_cleaning }} messages are split {{ split.train_rows }}/{{ split.test_rows }} with train_test_split(test_size={{ split.test_size }}, random_state={{ split.random_state }}, stratify=y), so both parts keep the same spam ratio.
  3. Each algorithm is a scikit-learn Pipeline: text cleaning → TfidfVectorizer → classifier. The vectorizer is fitted on the training split only, so no test message influences the vocabulary or the IDF weights.
  4. Predictions are made once on the untouched test split and compared with the true labels: accuracy, precision, recall, F1 (positive class = spam), ROC-AUC and the confusion matrix.
  5. Cross-validation ({{ cv_folds|default:5 }}-fold stratified F1 on the training split) is reported as a stability check, not as a headline score.

Score types. Naive Bayes and Logistic Regression expose predict_proba, so a probability of spam can be reported. The Linear SVM only exposes a decision margin, which is reported as a signed distance - never converted into a fake percentage.

Environment. Trained with scikit-learn {{ environment.scikit_learn }}, pandas {{ environment.pandas }}, NumPy {{ environment.numpy }} on {{ environment.platform }}. Total training time {{ results.duration_seconds }} s (CPU only).
