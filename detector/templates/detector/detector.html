How to read the result

  • • Ham means the model considers the message ordinary; Spam means unwanted, promotional or fraudulent-looking content.
  • • The model name is shown because the three algorithms can disagree on borderline messages.
  • • Naive Bayes and Logistic Regression report an estimated probability of spam. The Linear SVM reports the distance from its decision boundary (a margin), which is not a probability.
  • • Inference time is measured on this server for this request only.
  • • A confident answer is still only a statistical estimate: legitimate messages can be flagged and sophisticated spam can slip through. Never rely on this tool as the only protection.
