What the tool does

educational
  • ● Accepts one English SMS and validates it (empty or oversized input is rejected with a clear message).
  • ● Runs a real trained model - you choose Naive Bayes, Logistic Regression or the Linear SVM.
  • ● Reports the predicted class together with the model name, the inference time and an honest note about what the model score means.
  • ● Publishes its own evaluation - accuracy, precision, recall, F1-score (spam = positive class) and confusion matrices measured on a held-out test split.

Not implemented: URL reputation checks, e-mail or messaging-app integration, user accounts, continuous background scanning or any form of real-time protection. The model only reads the text you paste.

What this project actually delivers

Works today

  • • Classification of a single English SMS into Ham or Spam.
  • • Selection between three independently trained models.
  • • Measured evaluation metrics and confusion matrices for all three.
  • • Reproducible training through one Django management command.
  • • Docker-based development environment and automated tests.

Known limits

  • • Trained on a 2011 UK corpus: modern wording may be misclassified.
  • • Only the message text is used; sender metadata is unavailable.
  • • Scores are model estimates or margins, never proof of safety.
  • • English messages only.
